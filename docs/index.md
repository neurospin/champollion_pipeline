# Champollion Pipeline

End-to-end pipeline from raw T1 MRI to sulcal embeddings, in six stages:
**Morphologist → Cortical tiles → Config → Embeddings → Combine → Snapshots.**

Developed at [Neurospin](https://joliot.cea.fr/drf/joliot/en/Pages/research_entities/NeuroSpin.aspx).
Source: [github.com/neurospin/champollion_pipeline](https://github.com/neurospin/champollion_pipeline).
